## 🎯 Objectif

La commande `stats` écrit aussi `stats/synthese.md`, le tableau de bord du tournoi, et remplit le winrate attendu :

```
  📊 games.csv            ⚙️ logiciel                              📈 rapports
┌──────────────────┐    ┌────────────────────────────────────┐    ┌─────────────────────────┐
│ games + fiches   │    │ python -m dcprepa stats <tournoi>  │    │ stats/<deck>.md         │
│ + méta papier    │ ─> │                                    │ ─> │   + winrate attendu     │
│ + méta général   │    │ calculer, comparer, écrire         │    │ stats/synthese.md  NEW  │
└──────────────────┘    └────────────────────────────────────┘    └─────────────────────────┘

synthese.md
├── Decks                 tous les decks côte à côte : statut, version, winrates, winrate attendu
├── Méta                  chaque oppo du méta × winrate de chaque deck contre lui
└── Matchups non testés   oppos du top 10 papier pas encore assez joués, par deck
```

**Terminé quand :** `python -m dcprepa stats relicfest-2026` écrit `stats/synthese.md` conforme au modèle (mis à jour),
le winrate attendu est rempli dans la synthèse et dans chaque rapport de deck, avec des tests pour chaque calcul.

**Hors de cette branche** ⏸️ : vraie CLI et saisie par le logiciel (`feat/cli`), interface graphique (`feat/gui`).

## 🔎 Les étapes en détail

### ✅ 1. Décisions 🤔

Tranché par l'utilisateur (2026-09-24) :

- ✅ **Méta du winrate attendu** : les **deux**, papier et général (deux valeurs).
- ✅ **Formule** : sur les **oppos joués du top 20 seulement**, poids ramenés à 100 % :

```
attendu = Σ poids(oppo) × winrate(deck contre oppo)  /  Σ poids(oppo)
          pour chaque oppo du top 20 (méta papier, ou général) contre lequel le deck a au moins une game (ou un BO3)

ex.  méta papier   Cloud 6 %   Phelia 5.2 %   Aragorn 5 %   (autres du top 20 : jamais joués)
     winrates      69.2 %      35 %           41.9 %
     attendu = (6 × 69.2 + 5.2 × 35 + 5 × 41.9) / (6 + 5.2 + 5) = 806.7 / 16.2 = 49.8 %
```

- ✅ **Base** : winrate par game **et** par BO3 (comme partout) → 4 valeurs par deck : papier / général × games / BO3.
- ✅ **Matchups non testés** : top 10 du méta **papier** ; decks au statut `envisage` ou `retenu` (les `ecarte` n'en ont plus besoin) ;
  non testé = moins de 10 BO3 **et** moins de 30 games contre l'oppo (un seul seuil atteint suffit pour être testé).

Tranché par l'utilisateur (2026-09-24, suite) :

- ✅ **Calcul sur les données disponibles seulement** : la part du méta non couverte (oppos jamais joués, hors top 20) n'entre pas dans le calcul (déjà le cas de la formule).
- ✅ **Couverture** (Σ poids des oppos joués) : affichée à côté du winrate attendu, `49.8 % (16.2 % du méta)`.
- ✅ **⚠️** si la couverture est inférieure à 30 % du méta (le top 20 pèse ≈ 63 %).
- ✅ **Aucun oppo joué du top 20** : `—`. **Self-play** : exclu.
- ✅ **Section Général du rapport de deck** : tableau Winrate / attendu papier / attendu général × Par game / Par BO3.
- ✅ **Tableau Decks de synthese.md** : méta papier seulement (le général reste dans les rapports de deck) ;
  colonnes Deck, Statut, Dernière version, Winrate (games), Winrate BO3, Attendu papier (games), Attendu papier (BO3) ;
  tri par statut (`retenu`, `envisage`, `ecarte`) puis attendu papier (games) décroissant.
- ✅ **Tableau Méta de synthese.md** : union des top 20 papier et général, triée par poids papier ; colonnes Poids papier, Poids général,
  puis une par deck `envisage` / `retenu` avec le winrate par game (`69.2 % (9/13)`, `—` si jamais joué).
- ✅ **Qui code** : Claude code et explique chaque étape (quoi, à quoi ça sert) ; l'utilisateur supervise et valide avant la suivante.

### 🔄 3. Matchups non testés 🔍
