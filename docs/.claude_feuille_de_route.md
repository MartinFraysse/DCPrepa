# Feuille de route du projet

> Les branches faites et celles qui restent pour finaliser DCPrepa, dans l'ordre conseillé.
> Tenue par Claude : une ligne change de statut quand une branche démarre ou est fusionnée dans `main`.
> Chaque branche a son plan détaillé (`docs/.claude_plan_<sujet>.md`, à partir de `docs/.claude_plan_modele.md`).
> Légende : ✅ fusionnée · 🔄 en cours · 🔜 prochaine · ⬜ à faire · 💡 idée, pas encore décidée

**Dernière mise à jour :** 2026-09-24

## 🗺️ Vue d'ensemble

```
 ✅ feat/project-setup      structure du dépôt, règles, doc                    🏗️
        │
 ✅ feat/format-data        data/, modèle de tournoi, rapports-modèles  (#1 #2) 🗂️
        │
 ✅ feat/import-inbox       inbox.yaml ──> games.csv                    (#3)    📥
        │
 ✅ feat/stats-deck         games.csv ──> stats/<deck>.md               (#4)    📊
        │
 🔄 feat/import-meta        MTGTop8 ──> meta/AAAA-MM-JJ/ (général + papier)     🌍
        │
 ⬜ feat/stats-synthese     stats/synthese.md, winrate attendu, non testés      🧭
        │
 ⬜ feat/cli                vraie CLI (interfaces/cli/) + saisie par le logiciel ⌨️
        │
 ⬜ feat/gui                interface graphique                                 🖥️

 En parallèle, à tout moment :
 ⬜ docs/…                  pages officielles manquantes de docs/               📚
```

Pourquoi cet ordre : la synthèse a besoin du méta (poids, top 10) ; la vraie CLI et la GUI appellent
les services existants, autant qu'ils soient tous là avant.
